# 모니터링 대시보드

가격·매물·발표 알림을 한 화면에서 확인하는 정적 대시보드입니다.

- 사이트: <https://dino790.github.io/>
- 갱신: `data.json` 한 파일만 고치면 화면에 반영됩니다(브라우저는 캐시를 피해 매번 새로 받습니다).

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 대시보드 화면 (모바일 우선, 라이트/다크 자동, 5분마다 자동 갱신) |
| `data.json` | 감시 항목 데이터 (`updated_at` + `items` 배열) |

## data.json 형식

```json
{
  "updated_at": "2026-11-17T11:57:00+09:00",
  "headline": "요약 한 줄 (선택)",
  "items": [
    {
      "icon": "✈️",
      "title": "항목 이름",
      "subtitle": "부제 (선택)",
      "status": "watching",
      "status_label": "감시 중",
      "condition": "목표 조건",
      "latest_value": "최근 확인 값",
      "latest_label": "값에 대한 설명 (선택)",
      "gap": "목표까지 남은 차이 (선택)",
      "observed_at": "2026-11-17T11:02:00+09:00",
      "source": "확인 경로 (선택)",
      "note": "메모 (선택)"
    }
  ]
}
```

### status 값

| 값 | 배지 | 의미 |
| --- | --- | --- |
| `watching` | 감시 중 (파랑) | 정상 감시, 조건 미충족 |
| `hit` | 조건 충족 (초록) | 목표 조건을 만족한 항목 |
| `waiting` | 대기 (주황) | 상대측 발표·개시를 기다리는 상태 |
| `idle` | 중지 (회색) | 감시 중단·종료 |

요약 숫자(항목 수·조건 충족·감시 중)와 상단 요약 문구는 `items`에서 자동 계산됩니다.

## 갱신 방법

1. `data.json`의 `updated_at`과 해당 항목의 `latest_value`·`observed_at`·`note`를 고친다.
2. 커밋 후 `main` 브랜치에 푸시한다.
3. GitHub Pages 반영에 수십 초 걸릴 수 있고, 열려 있는 화면은 5분마다 또는 새로고침 버튼으로 새 데이터를 받는다.

## 참고

- 검색엔진 수집을 막기 위해 `index.html`에 `noindex` 메타 태그를 두었습니다.
- 별도 빌드 과정이 없는 순수 정적 파일입니다(`.nojekyll`로 Jekyll 처리 생략).
